# AH Advance Geotechnical Consultancy Website

A clean, responsive website for a geotechnical consultancy. This static site uses plain HTML, CSS, and JavaScript.

## Files
- `index.html` — landing page structure
- `styles.css` — responsive styling and layout
- `script.js` — mobile menu toggle and smooth scrolling

## How to use
1. Open `index.html` in a browser.
2. Edit the content and branding to match your service.

## Customize
- Update the company name in `index.html`.
- Add your own service descriptions, testimonials, and contact information.
- Replace placeholder text with real business details.
